# Marketer Ai — منصة صناعة المحتوى التسويقي

منصة عربية تحوّل هوية المتجر ومنتجاته إلى محتوى تسويقي جاهز للنشر: كتابة، كاروسيل، صور، وخطة شهرية.

هذه **الموجة صفر والأولى** من خطة التنفيذ: الأساس + قلب المنصة.

---

## التشغيل

### الطريقة السريعة على ويندوز

انقر مرتين على **`setup.bat`** — يتحقق من المتطلبات، يثبّت الحزم، ينشئ قاعدة البيانات،
يشغّل الهجرات والبيانات التجريبية، ويبني الواجهة. ثم انقر **`start.bat`** لتشغيله.

الدخول: **demo@marketer.test** / **password**

### المتطلبات قبل النقر
- PHP 8.2 فأعلى في مسار النظام
- Composer 2
- Node.js LTS
- خادم MySQL 8 يعمل (Laragon أو XAMPP أو خدمة MySQL)

`setup.bat` يفحص إضافات PHP بنفسه ويخبرك بالناقص منها وبمسار `php.ini` الذي تعدّله.
الإضافات اللازمة: `pdo_mysql`, `mbstring`, `fileinfo`, `openssl`, `curl`, `zip`, `tokenizer`, `xml`, `ctype`, `dom`, `filter`, `hash`, `session`, و`gd` مستحسنة.

**ملاحظة ويندوز:** إضافتا `pcntl` و`posix` غير موجودتين على ويندوز إطلاقاً.
لهذا لا يحتوي المشروع على `laravel/horizon` ولا `laravel/pail` — كلاهما يشترطهما.
Horizon يُضاف على خادم الإنتاج لينكس حيث يوجد Redis:

```bash
composer require laravel/horizon
```

> `setup.bat` ينشئ قاعدة `marketer_ai` بنفسه — لا تحتاج إنشاءها يدوياً.
> إن كانت كلمة مرور MySQL تحوي `%` أو `&` أو `^`، اتركها فارغة في السكربت وضعها يدوياً في `.env` بعد انتهائه.

### الطريقة اليدوية

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

# عدّل DB_* في .env ثم:
php artisan migrate --seed
php artisan storage:link
npm run build
```

ثم في طرفيتين منفصلتين:

```bash
php artisan serve
php artisan queue:listen --queue=content,media,default --tries=2 --timeout=600
```

افتح <http://localhost:8000>

> **إلزامي:** الطابور يجب أن يستمع لـ `content` و`media` تحديداً.
> الأمر وحده بلا `--queue` يستمع لطابور `default` فقط، فتبقى كل مهام التوليد في الانتظار للأبد.
> بديل سريع في التطوير: `QUEUE_CONNECTION=sync` في `.env` لتنفيذها فوراً داخل الطلب بلا عامل.

> **في التطوير `queue:listen` لا `queue:work`.** `queue:work` يحمّل الكود مرة ويبقى عليه:
> بعد أي تحديث للكود أو لمزود الذكاء في صفحة الإعدادات يظل يعمل بالقديم — وبالمزود الوهمي —
> حتى يُعاد تشغيله، فتخرج الأوصاف والمنشورات «[نص تجريبي]» دون خطأ ظاهر.
> في الإنتاج `queue:work` أسرع، بشرط `php artisan queue:restart` بعد كل نشر.

### تشغيل النماذج الحقيقية

المنصة تعمل افتراضياً بمزود **وهمي** بلا مفاتيح ولا تكلفة، فتستطيع تجربة كل المسارات فوراً.
للتحويل إلى نموذج حقيقي، في `.env`:

```env
AI_TEXT_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...

AI_IMAGE_PROVIDER=openai
OPENAI_API_KEY=sk-...
```

ملف الهوية يُولَّد نادراً وكل منشور بعده يقرؤه، فيمكن توجيهه وحده لنموذج أقوى
دون تغيير نموذج المحتوى اليومي (يحتاج مفتاح ذلك المزود؛ بدونه يُستخدم الافتراضي):

```env
AI_PROFILE_PROVIDER=openai      # فارغ = المزود الافتراضي
AI_PROFILE_MODEL=gpt-4.1        # مع OpenRouter افتراضياً يكفي: AI_PROFILE_MODEL=openai/gpt-4.1
```

قارن النماذج بـ `php artisan brand:eval-profile --show`: يكتب مع كل تشغيل تقريراً في
`storage/app/brand-eval.html` يُفتح في المتصفح — طرفية ويندوز تعرض العربية معكوسة الحروف.

## ثلاثة قرارات معمارية تحكم كل شيء

**١. لا استدعاء نموذج داخل طلب HTTP.**
كل توليد يدخل طابوراً ويُستطلع من الواجهة عبر `/api/jobs/{uuid}`.
الفيديو البطيء لا يعطّل كابشن مدته ثلاث ثوانٍ لأن لكل نوع طابوره.

**٢. النقاط تُحجز قبل التنفيذ وتُسوّى بعده.**
الخصم بعد النجاح فقط يسمح لمستخدم برصيد خمس نقاط بإطلاق مئة مهمة متزامنة.
وعند الفشل الجزئي — أربع صور نجحت من ست — يُسلَّم الناجح وتُرجَع نقاط الفاشل وحدها.

**٣. لا يستدعي أي كود مزوداً مباشرة.**
كل شيء يمر بـ `AiManager`. تبديل مزود رفع أسعاره يصير تغييراً في `.env` لا في الكود.
وهو المكان الوحيد الذي تُسجَّل فيه التكلفة الحقيقية في `ai_usage_logs`.

## جودة المخرجات تأتي من `config/content.php`

لا من النموذج. الملف يحوي:
- **الأهداف** وتوجيه كتابة لكل هدف
- **المنصات** وحدود الطول والهاشتاقات وأسلوب كل منصة
- **أشكال المحتوى** لكل منصة (Reels، Story، Thread، سنابة…) وحقولها التابعة: مدة الفيديو، مدة القصة، عدد التغريدات
- **القوالب** وبنية شرائح الكاروسيل: هوك ← وعد ← جذب ← حصاد ← طلب. لا يختارها التاجر: تُختار من الهدف والشكل (`template_for`)
- **القواعد الملزمة**: لا اختراع أرقام، لا ادعاءات طبية، لا مقارنة بمنافس بالاسم

تعديل هذا الملف يغيّر سلوك كل التوليدات فوراً بلا نشر كود.

### بوابة الصدق

البرومبت يوجّه، لكنه لا يضمن. لذلك يُفحص كل منشور بعد توليده (`ContentQualityCheck`)
مقابل بيانات التاجر نفسها: رقم أو تقييم أو كود خصم أو شهادة عميل أو خدمة (توصيل، ضمان، هدية)
لم يذكرها التاجر = خطأ يُعاد للنموذج مرة واحدة مجاناً مع مسودته. ما يبقى يظهر للتاجر «راجع قبل النشر».
الكلمات الممنوعة تُلتقط بكل تصريفاتها (`ArabicText`)، والادعاءات ومفردات اللهجات في
`config/claims.php` و`config/dialects.php`.

```bash
php artisan content:eval        # يقيس الأخطاء قبل البوابة وبعدها على النموذج الحقيقي
```

بعد البوابة يمر **مدقق لغوي** تلقائي (`Proofreader`) يصلح الإملاء فقط؛ ما يغيّر رقماً أو يعيد الصياغة يُرفض.

مصدر الحقائق المسموحة: بيانات المنتج، وملف الهوية، وصفحة **حقائق البيع** (`/store/facts`):
التوصيل والدفع، والعروض والأكواد بتواريخها، وتجارب العملاء بإذنهم. العرض المنتهي يختفي من البرومبت تلقائياً.

### استوديو الصور

اختيار النموذج في `/studio` فعلي حين يكون مزود الصور **OpenRouter** (Nano Banana 2، GPT Image 2.5 Sunburst/Flare،
Grok Imagine، Grok Imagine 2.0 — `config('ai.studio_models')`)؛ قدرات كل نموذج (الدقات/الجودات/النسب) تُقرأ حياً منه،
وما لا يدعمه يُعطَّل في الواجهة ويُرفض قبل حجز النقاط. الصور تُولَّد بالتوازي وتُحفظ لها مصغّرة للمعرض.

```bash
php artisan media:thumbnails    # مصغّرات للصور القديمة (الجديدة تُنشأ تلقائياً)
```

### التعليق الصوتي (Beta)

`/voiceover`: نص التاجر (أو محتوى من خطته) بصوت أحد 18 مذيعاً، بأسلوب إلقاء ولهجة. النطق عبر **Gemini TTS**
(`config/voiceover.php`)، ونموذج كل مستوى جودة ومزود الصوت يُضبطان من `/settings/ai`. المدة الفعلية أساس تسوية النقاط.

- التوجيه جملة واحدة قبل النص (`Read aloud …:`): الصيغة الطويلة بعناوين كان `gemini-3.8-flash-lite-tts` ينطقها.
- **حارس المدة**: تسجيل أطول بكثير من نصه (قرأ التوجيه أو كرر) يُعاد مرة، ثم تفشل المهمة وتُرجع النقاط.
- ملاحظات «أسلوب مخصص» العربية تُترجم لعبارة إنجليزية قبل النطق: النماذج تلتزم بالإنجليزية أدق.
- **مفتاح Gemini المجاني: 10 طلبات نطق يومياً لكل نموذج** (والعينات منها)، وتوليد الصور بحصة صفر — للتجربة فقط.

```bash
php artisan voiceover:samples --language=all   # عينات «استمع» لكل مذيع (--model لنموذج بعينه، --force لإعادتها)
php artisan voiceover:avatars                  # صور المذيعين في public/images/voices (تحتاج رصيد صور مدفوعاً)
php artisan voiceover:prune                    # حذف ما تجاوز 30 يوماً ولم يُحفظ (مجدول يومياً)
```
